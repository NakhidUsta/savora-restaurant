# Savora

Full-stack restoran veb saytı — React (Vite) + Tailwind frontend, Node.js/Express backend, SQL Server verilənlər bazası. Onlayn menyu, masa rezervasiyası, sifariş və müştəri rəyləri üçün tam funksional platforma, sayt məzmununu idarə etmək üçün admin panel ilə.
